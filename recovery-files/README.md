3. ✅ يُضيف جداول المساعد الذكي الجديدة (AIConversation, AIMessage, AuditLog)
4. ✅ يتأكّد من وجود مستخدم admin/admin123

## 🆘 في حالة المشاكل

### المشكلة: "Cannot find module '@prisma/client'"

**السبب**: الاعتماديات غير مثبّتة.

**الحل**:
```bash
npm install
npx prisma generate
node data-recovery/restore-data.cjs
```

### المشكلة: "prisma schema not found"

**السبب**: السكريبت لا يجد مجلد المشروع.

**الحل**: شغّل السكريبت من داخل مجلد المشروع:
```bash
cd C:\path\to\your-project
node data-recovery/restore-data.cjs
```

### المشكلة: "sqlite3 not found"

**غير مهم** — هذه رسالة تحذير فقط. السكريبت يستخدم sqlite3 للفحص فقط، لكنه يشتغل بدونه.

### المشكلة: فشل `prisma db push`

**الحل اليدوي**:
```bash
npx prisma db push
npx prisma generate
npx tsx scripts/create-admin.ts
```

## 💡 ملاحظات مهمة

1. **النسخة الاحتياطية**: السكريبت يحفظ نسخة من قاعدة بياناتك الحالية في `db/backups/` قبل الاسترجاع.

2. **جداول المساعد الذكي**: تُضاف تلقائياً عند تشغيل `prisma db push` — لا تؤثر على بياناتك الحالية.

3. **مستخدم admin**: السكريبت يتأكّد من وجوده بكلمة مرور `admin123`.

4. **بعد الاسترجاع**: يمكنك حذف مجلد `data-recovery` من مشروعك (لا تحتاجه بعد الآن).
