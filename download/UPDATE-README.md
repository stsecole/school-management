# 🚀 سكريبت التحديث الشامل — تحديث مشروعك بأمر واحد

## 📦 الملفات الموجودة

```
update.sh        ← السكريبت الوحيد الذي تحتاجه
```

---

## ⚡ طريقة الاستخدام

### 1️⃣ ضع السكريبت في مشروعك
```
your-project/
├── update.sh        ← ضعه هنا (بجانب package.json)
├── package.json
├── src/
├── prisma/
└── db/
    └── custom.db    ← قاعدة بياناتك (لا تُلمس أبداً)
```

### 2️⃣ عند وصول تحديث جديد مني

#### الطريقة الأسهل (مُوصى بها):
1. أنشئ مجلد `update-files/` بجانب المشروع
2. انسخ فيه الملفات الجديدة (src/, prisma/, إلخ)
3. شغّل:
```bash
bash update.sh
```

#### الطريقة البديلة:
1. ضع ملف ZIP في أي مكان
2. شغّل:
```bash
bash update.sh /path/to/update.zip
```

أو حدّد مسار المجلد:
```bash
bash update.sh ~/Downloads/new-files
```

### 3️⃣ انتهى! ✅

السكريبت سيقوم بـ:
- ✅ أخذ نسخة احتياطية من قاعدة بياناتك
- ✅ استبدال ملفات الكود
- ✅ تحديث الاعتماديات (npm install)
- ✅ تحديث قاعدة البيانات (بدون فقدان بياناتك)
- ✅ إرشادك لإعادة تشغيل التطبيق

---

## 📋 كل الأوامر المتاحة

| الأمر | ماذا يفعل |
|------|----------|
| `bash update.sh` | تحديث من مجلد `update-files/` |
| `bash update.sh /path/to/files` | تحديث من مسار مخصّص |
| `bash update.sh /path/to/update.zip` | تحديث من ملف ZIP |
| `bash update.sh --backup` | أخذ نسخة احتياطية فقط |
| `bash update.sh --list` | عرض كل النسخ الاحتياطية |
| `bash update.sh --restore` | استعادة أحدث نسخة احتياطية |
| `bash update.sh --restore FILE` | استعادة نسخة محدّدة |
| `bash update.sh --help` | عرض المساعدة |

## 🛡️ الأمان — ماذا يحدث لبياناتك؟

### ✅ ملفات تُستبدل (آمن — مجرد أكواد):
- `src/` — أكواد التطبيق
- `prisma/schema.prisma` — هيكل الجداول
- `public/` — الصور والأيقونات
- `package.json`, `next.config.ts`, `tsconfig.json` — إعدادات

### ❌ ملفات لا تُلمس أبداً (محفوظة):
- `db/custom.db` — **قاعدة بياناتك** (الطلاب، الدفعات، الأساتذة)
- `.env` — إعدادات البيئة
- `node_modules/` — يُعاد بناؤه بـ npm install

## 🆘 في حالة المشاكل

### مشكلة: التحديث فشل
```bash
# استعادة النسخة الاحتياطية
bash update.sh --restore
```

### مشكلة: التطبيق لا يعمل بعد التحديث
```bash
# تحقّق من النسخ الاحتياطية
bash update.sh --list

# استعادة نسخة محدّدة
bash update.sh --restore db/backups/custom.db.backup-20250703-105446

# أعد التشغيل
npm run dev
```

### مشكلة: "bash: permission denied"
```bash
chmod +x update.sh
bash update.sh
```

## ❓ أسئلة شائعة

### س: هل سأفقد بياناتي (الطلاب، الدفعات)؟
**ج:** لا أبداً! السكريبت:
- يأخذ نسخة احتياطية قبل أي شيء
- لا يلمس `db/custom.db`
- يُحدّث قاعدة البيانات بإضافة الجداول الجديدة فقط
- بياناتك القديمة تبقى كما هي

### س: كم مرة أحتاج لتشغيل هذا السكريبت؟
**ج:** فقط عندما أرسل لك تحديثات جديدة (ملفات src/ أو prisma/ جديدة).

### س: هل أحتاج لإيقاف التطبيق قبل التحديث؟
**ج:** يُفضّل. اضغط Ctrl+C في نافذة التطبيق، ثم شغّل السكريبت.

### س: ماذا لو لم أُنشئ مجلد update-files؟
**ج:** السكريبت سيُظهر رسالة خطأ تشرح ما يجب فعله.

### س: هل يعمل على Windows؟
**ج:** نعم، على Windows تحتاج:
- **Git Bash** (مُوصى به — يأتي مع تثبيت Git)
- أو **WSL** (Windows Subsystem for Linux)
- أو **PowerShell** (مع تعديل بسيط)

### س: ما الفرق بين هذا السكريبت و `server-update.sh`؟
**ج:**
- `update.sh` (هذا) — يُشغّل على **جهازك المحلي** لتحديث مشروعك
- `server-update.sh` — يُشغّل على **السيرفر** بعد رفع الملفات إليه
